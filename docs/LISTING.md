# Suggested Crafted Template listing

## Title

Nexora — Business Consulting React Template

## Short description

A refined consulting website with thoughtful typography, warm ivory surfaces, deep
green accents, and layouts designed for ambitious professional service brands.
Built with React and Vite, with editable content, static HTML generation, and a
documented path to your own backend.

## What is included

- 20 complete content pages and a designed 404 page
- Home, company, services, projects, journal, contact, and legal drafting outlines
- Four service pages, four illustrative case studies, and four sample articles
- Project category filters and journal topic filtering, search, and pagination
- Inquiry form with native validation, consent, accessible feedback, and API adapter
- Responsive CSS, modal mobile navigation, native FAQs, and reduced-motion styles
- Prerendered HTML, per-page SEO and social metadata, structured data, and sitemap
- Source code, prebuilt demo, setup guides, backend contract, and deployment guidance
- MIT license for template code; see asset notices for photography

## Technology

React 19 · React Router 7 · Vite 7 · Tailwind CSS 4 base styles · Lucide React
JavaScript/JSX · CSS custom properties · Node.js 22.12+ for builds

## Buyers should know

This is a frontend template. No CMS, database, email service, or hosted backend is
included. Connect your own inquiry endpoint using the documented adapter. Forms
run in explicit preview mode until an endpoint is configured. Brand details, team
profiles, case studies, and articles are fictional sample content. Legal pages are
drafting outlines to complete for your own organization. No accessibility score,
search ranking, client result, or WCAG certification is promised.
